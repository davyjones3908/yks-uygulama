# Sayfalar (Pages)

Bu klasörde uygulama ekranları/sayfaları bulunur.

## Yapı

```
pages/
├── HomePage/
│   ├── HomePage.jsx
│   ├── HomePage.css
│   └── HomePage.test.js
├── AuthPage/
│   ├── AuthPage.jsx
│   ├── AuthPage.css
│   └── AuthPage.test.js
└── ...
```

## Sayfa Yazma Kuralları

1. Her sayfa kendi klasöründe olmalı
2. Sayfanın ana bileşeni .jsx uzantısında olmalı
3. CSS dosyasını sayfayla aynı klasörde tutun
4. Router entegrasyonu yapılmalı
